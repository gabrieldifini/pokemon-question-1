# Run the App

```bash
  $ cd AirReadingInterviewApp
  $ pnpm install
  $ pnpm run dev
```

Navigate to http://localhost:5173/

# Tasks

3. Add search functionality. This should take the form of a UX element that allows the user to enter a string and filters the list of pokemon by that string.
4. Add a loading message or indicator while the content is loading from the API.
